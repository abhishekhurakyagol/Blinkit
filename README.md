## BlinkIT Grocery Dashboard
This Tableau dashboard presents a detailed overview of grocery item performance across categories, outlet locations, and pricing metrics. It is designed to support data-driven decision-making in retail operations.
# Key Insights
• 	Top-Selling Categories
 Fruits and Vegetables, Snack Foods, and Frozen Foods rank highest in total sales.
• 	Outlet Performance
Outlet 3 leads in sales volume, followed by Outlet 2 and Outlet 1.
• 	Fat Content Distribution
Items are categorized by fat content: Regular (47.3%), LF (36.2%), and Low Fat (16.5%).
• 	Average MRP by Item Type
Household items have the highest average MRP (₹144.48), while Starchy Foods have the lowest (₹143.48).
# Dashboard Features
• 	Bubble chart for item type distribution
• 	Bar charts for sales and pricing comparisons
• 	Pie chart for fat content segmentation
• 	Outlet-wise performance breakdown
# Tools Used
• 	Tableau for interactive visualizations
• 	Excel for data preprocessing and calculated fields
• 	Retail sales dataset for analysis
